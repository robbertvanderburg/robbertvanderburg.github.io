## What already worked

The browser retained the full 320 px document width in the initial phone probes. The masked portrait had reserved dimensions, the small WebP loaded on phones, and the main navigation offered Publications and CV directly. The existing preprint preview used a native disclosure. The CSS already honored reduced motion and the dark theme retained the paper hierarchy. These observations supported targeted edits.

The [baseline screenshot directory](screenshots/before/) contains one full-page WebP per route, theme and required viewport. Filenames encode both dimensions, including the two distinct 1024 px cases. [Test report](TEST-REPORT.md) records accessibility, performance, links, coverage and limitations.
